# One Sentence for a Traveler from 1800

Entry for the make.fun bounty `u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb`: one sentence, at most 200 characters, explaining the modern internet to someone arriving from the year 1800, using only words and pictures available in 1800.

## The sentence

> Imagine every library, post office and town square in the world joined by wires, so any letter, book or spoken word reaches any door in the blink of an eye.

156 characters. The internet is pictured as three institutions a person from 1800 already knows — the library (all knowledge), the post office (messages) and the town square (public talk) — joined by wires, with everything they carry arriving anywhere in the blink of an eye. One image, no list of features, no word coined after the traveler's time.

## How it runs

`main.py` writes the exact sentence above to `/output/entry.txt` (creating `/output` if needed). It is deterministic: every run produces byte-identical output.
